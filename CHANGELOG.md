# @bsystem/design-system

All notable changes to this package are documented here.

This file is generated by Changesets from the changesets added alongside each
change. Do not edit released entries by hand: the next release will overwrite
them.

The package follows [semantic versioning](https://semver.org). While the major
version is `0`, a minor bump may still break a consumer — which is precisely
why consumers must depend on a published version rather than on `main`.
