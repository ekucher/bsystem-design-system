# BSYSTEM Design System Roadmap

## P0 — Foundations

- naming conventions
- design tokens
- typography scale
- semantic colors
- spacing/radius/elevation tokens
- icon policy
- accessibility baseline
- package/build strategy

## P1 — Core components

- buttons
- form controls
- badges/statuses
- cards
- tables
- navigation primitives
- modal/drawer
- alerts/toasts

## P2 — Platform patterns

- application shell
- app switcher
- dashboard widgets
- global search UI
- notification center
- profile menu
- resource header
- breadcrumbs
- health/status presentation

## P3 — Advanced patterns

- data grids
- filters
- bulk actions
- audit timeline
- activity stream
- AI assistant panel
- RAG/search result presentation

## P4 — Third-party branding guidance

- authentik branding guidance
- EspoCRM theme/extension guidance
- Redmine theme/plugin guidance
- Outline branding guidance

The goal is visual consistency without creating hard dependencies on deep upstream forks.
